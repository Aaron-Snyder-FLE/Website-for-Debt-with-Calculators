# Debt Terms Lab

A small static breakout module for practicing debt vocabulary and exploring loan math.

## What is included

- Interactive flashcards for common debt terms
- Installment loan calculator for loan amount, APR, and term length
- Car loan extra-payment calculator with total interest comparison bars
- Mortgage extra-payment calculator with total interest comparison bars
- Credit card payoff calculator with a minimum payment floor of monthly interest plus 1% of balance
- Matching activity for pairing terms with definitions
- Second credit module page with credit terms, free report steps, and a credit decision simulator

## How to use

Open `index.html` in a browser, or upload this folder to GitHub Pages. The credit module is available from `credit.html`.

To edit the flashcards or matching activity, change the `terms` list in `script.js`.
